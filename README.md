Mobile Sales Analysis with GenAI & Power BI 📱
Project Overview
This project provides a comprehensive analysis of mobile phone sales data. It combines traditional data cleaning and machine learning with modern Generative AI to provide automated business insights.

Key Features
Data Cleaning & ML: Used Python (Pandas) to clean datasets and Scikit-Learn for simple price prediction based on ratings and discounts.
Data Visualization: Created an interactive Power BI Dashboard to compare brand performance and discount trends.
AI Insights: Integrated Google Gemini API (2.0 Flash) to automatically generate business summaries and strategic recommendations from the data.

Tech Stack
Language: Python 3.13
Libraries: Pandas, Seaborn, Matplotlib, google-genai
BI Tool: Power BI Desktop
AI Model: Google Gemini 2.0 Flash

How to Run
Install dependencies: pip install pandas google-genai
Run the data cleaning script: python my.py
Generate AI insights: python ai_summary.py (Ensure you have a Gemini API Key).
Open the .pbix file (if uploaded) or view the brand_report.png for visualizations.
